OP_RETURN

 

  • Blockhain sizes - Megabyte size of: overall blockchain, BIP158 filters, witnesses, script sigs and script pubkey

  • Witness stats - Stats about the witnesses, number of elements and bytes used

  • Number of inputs and outputs - Show how many txs have A input and B output

  • OP_RETURN - Charts showing the number of OP_RETURN scripts and fee spent per month.

  • OP_RETURN protocols - Protocols are guessed from the first 3 bytes of the data pushed after OP_RETURN (OP_RETURN OP_13 for Runes), which can indicate the protocol but it's not an enforced rule by the Bitcoin consensus. Known prefixes are labelled, unknown ones are shown as hex.

  • OP_RETURN sizes - Chart counting the number of OP_RETURN scripts per bucket of different sizes since inception.

  • Script types - Charts showing the script types per month.

  • Rounded amount - Charts showing the number of outputs which have a rounded amount as value (multiple of 1000)

  • Native segwit multisig - Analyze segwit input scripts counting the occurence of the NofM

  • Segwit script templates - Scripts revealed spending P2WSH, P2SH-P2WSH and taproot script path, with keys and hashes replaced by placeholders

  • Spent in the same block - Charts showing the number of output which are spent in the same block they are created

  • Number of sighash type used - Show distribution of sighash type used

  • Tx, inputs and outputs - Charts showing total number of transactions, inputs and outputs per month

  • BIP69 adoption - BIP69 compliance, ordered transaction inputs and outputs

  • Number of tx non-deeply reorgable - Number of transactions with nlocktime greater than confirmation height minus 6
