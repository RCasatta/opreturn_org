OP_RETURN protocols

Protocols are guessed from the first 3 bytes of the data pushed after OP_RETURN (OP_RETURN OP_13 for Runes), which can indicate the protocol but it's not an enforced rule by the Bitcoin consensus. Known prefixes are labelled, unknown ones are shown as hex.
